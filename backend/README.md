## Backend (Python + FastAPI)

This is:

document analysis
AI processing
prediction logic
APIs
file handling

The “brain” of the system.

Backend using virtual environment to avoid the Python mismatching versions. 

## FastAPI

This is the backend framework.

It helps create:

APIs
routes
file uploads
JSON responses

## Uvicorn

This is the web server.

FastAPI needs a server to run

### services/

Business logic.

Example:

PDF processing
insight generation

### ml/

Machine learning code.

Example:

prediction models
anomaly detection

### utils/

Helper functions.

Example:

cleaning text
formatting dates
models/

Data models / schemas.

The 'upload' folder is where the files need to be stored temporarily
